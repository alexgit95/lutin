Je veux creer une web application, installable sur telephone android au format PWA
Le but de cette application et la gestion des achats de masse avec Workflow
Je veux de bases la penser multi utilisateurs
Je dois pouvoir m'inscrire sur le site (login + mot de passe + clé invitation)
une fois inscrit je dois pouvoir creer un nouveau 
une fois connecte je dois pouvoir creer mes liste d'achat
Je dois pouvoir creer des personne (qui seront celle qui recoivent les cadeau) et leur affecter un budget
Ma page principale doit me permettre de creer une personne et lui affecté un budget
D'ajouter un cadeau, c'est à dire donner un nom (obligatoire), une url (falcutative mais le nom peut etre deduis du title de la page de l'url indioqué) et indiquer dans la liste de mes personnes qui en est le destinataire
Je peux vouloir acheter une cadeau à la place d'une personne, dans ce cas la je peux aussi l'indiquer
Chaque cadeau a ensuite le workflow suivant :
A Acheter -> Commandé -> Livré -> Emballé ->Remis
je dois évidemment pouvoir modifier un cadeau et le supprimer
Je dois avoir une page d'accueil dashboard qui me montre le statut de tous les cadeaux, ainsi que le budget global, le budget deja deboursé, le budget restant à payer et sur ce dashboard je dois pouvoir simplement changer le statut du workflow de chaque cadeau
Je dois ensuite pouvoir mettre des tags sur les cadeaux me perettant de facilement les regrouper ensemble
je dois pouvoir partager mon dashboard, avec un autre login qui existe sur l'appli ( une liste defilante de tous les logins doit apparaitre) et qui n'a que la possibilité de voir les données (pas les modifier)
Un cadeau peut aussi etre masqué, dans ce cas la personne avec qui on partage le dashboard voit une ligne avec son nom mais tous le reste doit etre masqué
